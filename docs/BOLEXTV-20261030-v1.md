# BolexTV — project overview

*Written 30/10/2026. Supersedes the phase documents as the single description of the system;
those remain as evidence of how each decision was reached.*

## What it is

BolexTV is Alex Benthem's own build of the Nostalgex web tuner: an endless "TV channel"
experience over a Plex library, with a guide, a player, and now subtitles, wrapped in an
Android TV shell for a Xiaomi Mi Box (`MiTV-AFMU0`, Android 14, 32-bit only).

It exists because the upstream project targets the browser and Apple TV, and this household
wants a television app driven by a six-button remote, branded as BolexTV, with no links back to
the creator and no telemetry.

## The rename: Nostalgex → BolexTV

The rename is **cosmetic at the surface and untouched at the data layer**. That split is
deliberate and is the reason the app still finds its content.

### What was renamed

| Where | What changed |
|---|---|
| `plex-tuner.html` | Page title, all five logo slots, sign-in strings ("RECONNECT TO SIGN IN AGAIN"), the session-ended copy |
| `web-tuner.html` | Header wordmark, footer lockups, `<title>`, Open Graph tags, JSON-LD, favicon and apple-touch icons |
| `tuner/logo/` | `bolextv-white.svg`, `bolextv-black.svg`, `favicon.png` (32 px), `favicon-48.png`, `apple-touch-icon.png`, `bolextv-512.png` |
| `tuner/bolextv.css` | A readability layer, scoped to `body:not(.retro-mode)` so RETRO still looks retro |
| Brand | The **Guide Play** mark: amber `#E9A13B`, ink `#12151A`, cream `#F2EAE1` — deliberately not Plex orange |

### What was deliberately NOT renamed

| Left alone | Why |
|---|---|
| Channel names `NOSTALGEX LOL`, `NOSTALGEX HORROR`, `NOSTALGEX CHRISTMAS` | They must match the generated channel packs, or the channels come back empty |
| `localStorage` key `nostalgex-theme-v2` | Renaming it would silently reset the user's saved theme |

Anyone tempted to finish the rename should stop at this table.

### Removed by instruction

- Every "buy me a coffee" element: the drawer entry, the loading screen, the settings footer.
- Every link to the creator: Apple TV download button, Instagram tile and drawer item, the
  eight footer social icons, the JSON-LD creator URL, and the `selfhost:only` GitHub anchor.

## The icon and the marks

One geometry source, `brand/build-brand-assets.py`, emits every asset — so the icon on the box,
the favicon in the browser and the banner on the launcher are all the same drawing. A rebuild was
verified deterministic: **10/10 byte-identical** outputs after wiping and regenerating.

| Asset | File | Use |

| Banner 320×180 | `brand/assets/bolextv-banner-320x180-20261029-v1.png` | Android TV `LEANBACK_LAUNCHER` |

## Architecture

Two halves, one rule: **the page owns what the user sees; the shell owns what the remote does.**

```
Mi Box (Android TV)                          LXC 228 on bolex (.5)
┌────────────────────────────┐               ┌─────────────────────────────┐
│ BolexTV APK                │  HTTP :8080   │ bolex-tv-tuner container    │
│  WebView  ────────────────►│──────────────►│  plex-tuner.html            │
│   · tvnav.js  (focus)      │               │   · guide + schedule engine │
│   · dispatchKeyEvent       │               │   · player + subtitles      │
│   · lifecycle + exit       │               │   · branding, 24 h clock    │
└────────────────────────────┘               └──────────────┬──────────────┘
                                                            │ Plex API :32400
                                                            ▼
                                                     Plex Media Server (.30)
```

- **`androidtv/app/src/main/assets/tvnav.js`** is the single navigation engine — geometric focus
  over visible controls, not "what has `.focused` today". There is exactly one copy; two earlier
  copies drifted twice and were deleted.
- **The page exposes a small JavaScript surface** the shell calls: `__tvOkPress`,
  `__tvHideGuide` / `__tvShowGuide`, `__tvTimeShift` / `__tvTimeShiftResume`, `__tvFsMenu`,
  `__tvPlexSubs`, `__tvGuideVisible`.
- **Nothing native depends on `evaluateJavascript` callbacks while video plays.** They stop
  arriving during playback; verification uses the WebView DevTools socket over
  `adb forward` instead.

## Known limits

- **Element fullscreen is rejected by Android WebView.** `requestFullscreen()` does not work, so
  "full screen" is a layout the page applies (`body.tv-full`), not the browser API. A desktop
  browser still gets the real thing.
- **AC3 direct-play files are silent.** Of 764 direct-play items, 16 (2.1 %) are non-AAC, all
  `mp4+h264+AC3`. The hardware *declares* AC3/EAC3 decoders; the measured matrix shows picture
  with no audio. Fix is a tuner-side force-transcode predicate — **not yet implemented**.
- **MKV never plays in the WebView** (11/11), but the tuner transcodes every MKV to HLS anyway,
  so this costs nothing in practice.
- **The Mi Box sits on `192.168.5.0/24`** while servers are on `192.168.2.0/24`; power-saving WiFi
  gives 105–1120 ms ping and adb drops periodically.
- **GitHub Actions never ran.** The fork has zero registered workflows and the enable endpoints
  return 404; only the repo owner can approve the first workflow run.
- **`tv.bolex.es` answers 401 to `curl`** (Pangolin auth), so it is only verifiable from a
  logged-in browser.

## Deploy

### Tuner image

LXC 228 has no buildx, so the image is built with the legacy builder and a patched Dockerfile:

```sh
# on the build host, from a pristine checkout
chmod +x docker/40-config.sh                      # otherwise /config.json 404s as uid 101
sed -i 's|^FROM --platform=$BUILDPLATFORM |FROM |' Dockerfile
sed -i 's|^COPY --chmod=0755 \(.*\)$|COPY \1|' Dockerfile
docker build -t bolextv-tuner:<TAG> .
```

Then gate the candidate on `:8081` before touching live:

```sh
docker run -d --name bolextv-gate -p 8081:8080 --read-only --tmpfs /tmp \
  --security-opt no-new-privileges:true -e NOSTALGEX_ENRICHMENT=on <IMAGE_ID>
curl -s http://127.0.0.1:8081/config.json     # expect "enrichment": true
```

Swap, keeping the previous container for rollback:

```sh
docker stop bolex-tv-tuner && docker rename bolex-tv-tuner bolex-tv-tuner-old<N>
docker run -d --name bolex-tv-tuner -p 8080:8080 --read-only --tmpfs /tmp \
  --security-opt no-new-privileges:true --restart unless-stopped \
  -e NOSTALGEX_ENRICHMENT=on <IMAGE_ID>
```

Rollback is the reverse: stop, rename, start the `bolex-tv-tuner-old<N>` you kept.

## Verifying on the device

The page is invisible to the shell while video plays, so verification goes through the WebView
DevTools socket:

```sh
PID=$(adb shell pidof es.benthem.bolextv)
adb forward tcp:9222 localabstract:webview_devtools_remote_$PID
curl -s http://127.0.0.1:9222/json      # the WebView must be foregrounded
```

A backgrounded WebView lays out at zero size, so results taken while another app is in front are
meaningless — a trap that has produced false "it is broken" readings more than once.
